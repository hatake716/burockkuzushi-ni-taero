# NEON REGEN FESTIVAL

このゲーム向けに制作したオリジナル曲。生成元は `tools/generate_audio.py`。

- テンポ：180 BPM、4/4拍子、32小節。
- キー：A minor。
- 主進行：F→G→Am→Am（短調の♭VI→♭VII→i）。
- 長さ：約42.666667秒。44.1kHz、ステレオVorbis。
- パート：明るい電子音リード、倍音合成ピアノ、ベース、キック、スネア、ハイハット、クラッシュ。
- ８小節ごとに旋律や楽器の配置を変え、後半にピアノ中心の区間を設ける。
- 16分音符のピアノ分散和音、４つ打ち、打ち込みのフィル、左右に振ったディレイで速度感と祭りの賑やかさを作る。
- 末尾の音の余韻はループ先頭へ折り返して混ぜ、ループ接続部の無音を避ける。
- 全体の信号をソフトリミッターへ通した後、ピークを0.89へ正規化する。

「ZUN進行」の解釈にあたり、[東方Projectの楽曲と音楽理論の考察（試論）](https://harimusic.net/pdf/trial002.pdf) に記された短調のi・♭VI・♭VIIを用いる分析を参照した。
その和声的な材料を使って新しい旋律を作曲しており、既存楽曲の旋律・音源・MIDIの転載や編曲ではない。

## SE

| 音 | 合成方式 |
| --- | --- |
| burst.wav | 下降する正弦波＋減衰ノイズ。再生ごとにピッチを変えて花火を表現 |
| restore.wav | ピアノ高音と電子音の短い上昇感 |
| slot.wav | ４音の上行アルペジオ |
| cheat.wav | 低周波と振幅変調による警告音 |
| bounce.wav | 短いピアノ系の打音 |

SoundPoolの同時発音は16ボイス。ブロック破壊イベントごとに発音要求を行い、多発時は古い発音が置き換わる。
MediaPlayerでBGMをループ再生し、ユーザーの音量キーはメディア音量を操作する。
音楽、効果音、振動は別々にON/OFFを保存する。

## 再生成

```sh
python3 -m pip install numpy
python3 tools/generate_audio.py
```

FFmpegがPATH上に必要。乱数シードは固定。外部の録音・楽器サンプル・音楽ファイルをダウンロードしない。
エンコーダーの版によって圧縮ファイルのバイト列は変わる場合がある。
