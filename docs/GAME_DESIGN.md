# 実装仕様 1.0.5

## 仕様の確定

依頼文のスロット周期には５秒と７秒の記載があったため確認し、ユーザー回答により**７秒**に確定した。
玉数リセットは初期値１玉へ戻す。分裂は１玉が２玉になるため、１回のブロック衝突につき子を１玉追加する。
貫通と分裂の重複は、既に有効な残り時間へ５秒追加する形で実装した。

1.0.1で「玉＋５＆５秒貫通」「現在の速度×３＆５秒分裂」の複合出目を追加し、全９種類が各1/9の確率で抽選される。
複合出目は同時に２効果を適用し、通知・スロット当選回数は各１回。新しい玉にも貫通と既存の速度倍率が適用される。
玉数増加と速度倍率はリセットされるまで維持され、貫通・分裂部分だけが時間で失効する。
同種の貫通・分裂が有効なら残り時間に５秒加算。既存の玉数・速度リセットは複合出目から得た増加分にも適用する。
既存の保存済みゲームとランキングは引き継ぐ。保存済み出目は列挙名で記録されているため、既存７種類の名前を保持する。

## 表示言語

`values/strings.xml`を英語、`values-ja/strings.xml`を日本語とする。タイトルの英語名は「Survive Breakout!」。
日英の文字列リソースを定義し、画面・ダイアログ・全９種類の出目・読み上げ文言から参照する。
文字列分離は[Androidのローカライズガイド](https://developer.android.com/guide/topics/resources/localization)に沿う。

最優先の言語コードが`ja`なら日本語、それ以外は英語。国・地域では判定しない。
Androidのリソース照合は対応言語を優先順位リストの途中から選ぶ場合があるため、元の優先順位リストを判定してから画面のContextを日本語か英語に固定する。
Android 13以降ではLocaleManagerのシステム言語（アプリ別言語を明示設定していればその言語）、それ以前ではシステムResourcesの言語一覧を用いる。
英語画面はアラビア語などの端末でも左から右に配置する。フランス語→日本語という優先順位でも英語表示になる。

言語変更時は通常のActivity再生成で表示を更新する。保存キー、出目の列挙名、記録形式は維持し、途中のゲーム・ランキング・設定を引き継ぐ。
スコアの数字・桁区切りは明示的なLocale.USを使用し、端末言語に関係なく`1,234.5678`形式。ランキングの日付表記は画面の言語に合わせる。

## ゲームループと時間

Android `SystemClock.elapsedRealtimeNanos()` による単調増加クロックを入力とする。
画面フレームごとの実経過ナノ秒を渡し、遅いフレームでも経過時間を切り捨てない。
物理の計画区間は最大４ms。スロット境界・効果の失効境界でも区間を分割する。
各区間では全玉の次の衝突時刻を比較し、最も早い衝突から順番に処理する。
最後のブロックが消える接触時刻で終了し、その後のフレーム残余は加算しない。

ランキング保存単位は100μs（0.0001秒）。`ticks = elapsedNanos / 100000`。
スコアは `BigInteger(ticks)² / 10⁸` を `BigDecimal` で求めるため、整数乗算の桁あふれと浮動小数点の順位ずれを避ける。
スコア表示は小数４桁、切り捨て。順位は生存tickの降順、同点は達成日時の早い順。
小数４桁は保存・表示の分解能を示し、Androidの画面更新や入力・物理計算が10,000Hzで動くという意味ではない。

## 衝突とCPU

- 固定論理座標：幅800×高さ1050。物理計算は端末間で共通。表示側は各マスの48dp以上の操作領域を確保するため、ブロックの5行と上下の領域を区分して高さを変換する。幅が足りない場合は横スクロールする。
- 玉の半径７、初速440論理単位/秒。速度効果は全玉に共通の乗算係数で、新しい玉にも適用。
- パドル幅126、最大速度4200論理単位/秒。パドルは毎区間、目標へ速度上限を守って平行移動。
- CPUは下降中の玉の到達時刻と壁反射後の到達位置を予測し、間に合う玉のうち最も早いものを選ぶ。
- ブロックの矩形を玉の半径で広げた領域とのswept collisionを使用。高速玉のトンネリングを防ぐ。角は半径拡張矩形による近似。
- 玉同士の物理衝突はない。
- パドル反射は残存ブロックを狙う。孤立ブロックに届かない定常軌道による長い停滞を避ける。
- 回収できずに全玉が落ちた場合、0.65秒後に現在の速度・効果を保って１玉を再発射する。
- 玉数・速度倍率を密かに切り詰めない。極端な長時間増殖での端末性能は有限であり、無制限の処理性能を保証するものではない。

## 入力

タッチはDOWN時に候補を保持し、同じセル上でUPした時に１個再生する。
途中の複数ポインター検出は候補を破棄し、ゲーム時間で３秒のロックを設定する。
２本目が入った時点で１本目による再生も未確定なので、同時再生の抜け道を作らない。
ロック中に始まった操作・キャンセルされた操作・端末のタッチスロップを越えたドラッグは再生しない。ドラッグは親の縦・横スクロールに渡す。
警告中の追加ポインターで警告終了時刻は延長しない。

## ライフサイクルと保存

- タイトル→開始→３秒の合図→プレイ→全滅→結果→再挑戦またはランキング。
- プレイ中の戻る操作、フォーカス喪失、バックグラウンド移行で一時停止。
- 一時停止中は経過時間・警告残時間・スロット周期・特殊効果を含めて凍結。
- 再開の合図中も生存時間を加算しない。
- ゲーム状態をローカル保存。Activity再生成・プロセス再起動後はタイトルに「つづきから耐える」を表示。
- 保存済みプレイがあるときの「新しくはじめる」には、縦配置・折り返し可能な確認ダイアログを表示する。上書きボタンだけが保存を置き換え、キャンセル・戻る・外側タップでは保存を変更しない。
- 終了時にランキングの更新と中断データ削除を同一の同期保存トランザクションで行う。
- ゲームIDによる重複排除。上位100件を越える低い記録は保持しない。
- BGM・SEはバックグラウンドで停止。別アプリへのオーディオフォーカス移行でも一時停止する。
- `KEEP_SCREEN_ON` は前景のプレイ・再開カウントダウンだけで有効。タイトル・一時停止・結果・各ダイアログ・バックグラウンドでは解除する。

## 文字サイズとアクセシビリティ

- テキストはSPで指定し、端末の文字サイズに追従する。固定座標の文字描画を通常のTextView・Buttonへ移し、折り返しと縦スクロールで情報を保持する。DotGothic16を維持する。
- 一時停止は右上の固定領域に置き、最小高さ56dp・幅64dpを確保する。盤面の40マスは重複しない独立領域で、それぞれ48dp以上。
- ブロックあり・カウントダウン中・再生禁止中はクリックアクションを公開しない。読み上げでは位置・状態・再生できない理由を説明する。空きマスかつ再生可能な場合だけButtonとして公開し、実行時も最新状態を検証する。
- スコア欄、詳細状況欄、任意の「現在の状況を読み上げる」操作で、経過秒数、スコア、残存ブロック、玉数、速度、次の抽選・貫通・分裂・再生禁止の残り秒数を取得できる。ゲームに総制限時間はなく、経過時間と各タイマーの残り時間を区別する。
- 玉数・残存ブロック数はPOLITEライブ領域で、変化があるときだけ最短5秒間隔で通知する。特殊効果・再生禁止警告は発生時に通知して定期通知の間隔をリセットする。表示用のスコア・時間の毎回の変更は自動読み上げ対象にしない。
- 通常表示はスコア・時間が100ms間隔、詳細タイマーが1秒間隔。保存の100μs単位と物理計算は従来どおり。
