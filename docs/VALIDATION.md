## Android操作テスト

Android 15 / API 35 / x86_64 / 1080×2400の専用エミュレーター `emulator-5554` で10件成功。
実際のMotionEvent複数ポインター入力とUI Automator操作を使用した。

1. 遊び方・音と演出の表示、BGM設定の保存。
2. タイトルから開始、３秒のカウントダウン、実進行、一時停止中の時間停止。
3. 単指のDOWNでは再生せず、UPで指定した１セルだけを再生。
4. 実際の２本指入力で両セルを再生せず、３秒後の単指操作を受け付ける。
5. 空きセルを横断するドラッグでは再生しない。
6. ACTION_CANCELによる候補破棄と、その後の正常なタップ。
7. ７秒の境界でスロット効果を適用する。
8. Activity再生成後に盤面・倍率・警告残時間を復元する。
9. 最後のブロック破壊→結果画面→ランキング保存と表示、重複登録なし。
10. 105件から上位100件が別の保存インスタンスでも読み出せる。

テスト用の特殊な盤面・経過時間はテストコード内だけで設定する。製品にデバッグ操作やチート起動パラメーターは設けていない。
連続描画に対して通常の「画面が静止するまで待つ」処理が停止するため、テストは個別状態を条件に待機する。
タイトルは約12.5fpsの控えめな環境アニメーションにし、一時停止・結果画面の継続再描画を止めた。
