# 1.0.4 — ゲームボーイ風フォント

2026-09-14。`io.github.hatake716.taero` / versionCode **5**。

## 変更

ゲーム内の書体を、日本語・英数字対応のDotGothic16に統一しました。Canvasで描くタイトル、スコア、時間、スロット、通知、警告、ボタンに加え、遊び方、設定、ランキング、プライバシーポリシーのAndroid標準ダイアログにも適用しています。太字の合成でドット形状を変えず、文字色・サイズで強調します。幅に合わせた縮小処理は維持します。ゲームルール・音楽・保存形式・言語の選択方法は変更していません。

フォントはアプリに同梱するため、起動時のダウンロードはありません。配布元の著作権・OFL 1.1をassetsに収録しています。[配布元とハッシュ](../FONTS.md)

## 検証

- JVMテスト35件成功、`lintDebug` / `lintRelease` 成功。
- debug / release APK、AAB、AndroidTest APKのビルド成功。
- API 35エミュレーター、1080×2400で日本語UI13件、英語UI13件、言語テスト3件成功。
- 日本語テストの最初の試行は別の言語実行を開始したため中断。完走するまで再実行し、上記件数は完走した結果のみを記録しています。
- 日英のタイトル、複合スロット通知、スコア、設定、遊び方、結果などの実表示を目視確認。ゲーム画面・Androidダイアログの双方でドット文字になり、確認画面に文字欠落やボタンのはみ出しはありません。
- フォントのUnicode文字マップを調べ、日本語・英語リソースおよび `Ⅱ²→×0123456789.,+-` の欠落がないことを確認。
- 署名付きAPK/AABの中にフォント本体とライセンスが同じバイト列で含まれることを確認。
- AABの署名とbundletool validate、APKのv2/v3署名を確認。
- Pixel 10a（Android 17）を既存の開発用署名と一致するAPKで、1.0.2から1.0.4へ `adb install --no-incremental -r` により更新。Success、versionName 1.0.4 / code 5、起動成功を確認。初回インストール日時を維持し、アンインストール・データ消去・実機への操作ジェスチャーは行っていません。実機での全面的な手動プレイ確認とは区別します。
