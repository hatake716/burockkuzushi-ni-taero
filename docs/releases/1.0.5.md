# 1.0.5 — アクセシビリティ・操作領域・保存確認・画面点灯

2026-09-28。`io.github.hatake716.taero` / versionCode **6**。

## 報告された7件への対応

| 指摘 | 修正後の動作 |
|---|---|
| ゲーム進行のステータスが読み上げ対象にない | 上部のスコア欄・詳細欄・任意の読み上げボタンから経過時間、スコア、残存ブロック、玉数、速度、次の抽選と各効果の残り時間を取得。玉数・ブロック数のPOLITEライブ通知は変化時のみ最短5秒間隔。効果・複数指警告は発生時に通知。 |
| intactなブロックまでクリック可能 | 空きマスかつ再生可能な場合だけButton・ACTION_CLICKを公開。ブロックあり・再生禁止・カウントダウン中は状態と理由を説明し、クリックを公開しない。実行時にも最新状態を再確認。 |
| 端末の文字サイズが反映されない | 固定座標で描いていたメニュー・HUDをSP指定の通常のTextView・Buttonへ移行。折り返しと縦スクロールを使用。DotGothic16は維持。 |
| ブロックの操作領域が小さい | 40マスに重複しない48dp以上の操作領域。狭い画面では盤面を縮めず横スクロール。スワイプでは再生しない。 |
| 新規開始で保存が即時上書きされる | 保存がある場合に確認。キャンセル・戻る・外側タップでは保存を維持。「上書きして開始」のみ新規データを保存。文字サイズ2倍でも縦配置のボタンを折り返して操作可能。 |
| 一時停止が約32dp高 | 右上に幅64dp・最小高さ56dpのボタンを固定。ゲーム内容を縦スクロールしても操作可能。 |
| タイトルなどでも常時点灯 | 前景でのプレイ・カウントダウンに限ってKEEP_SCREEN_ONを有効化。タイトル・一時停止・結果・各ダイアログ・バックグラウンドで解除。 |

盤面の描画には表示専用の座標変換を使い、ゲームエンジンの物理座標・CPU動作・7秒スロット・9種類の効果・保存形式は変更していません。スコアの時間分解能は100μs、表示は小数4桁のままです。画面上の時間・スコアは100ms、詳細タイマーは1秒間隔で更新します。

UI検証は合計 **68件成功**。標準サイズではアクセシビリティ9件＋既存のゲーム操作13件＋言語3件。拡大サイズではアクセシビリティ9件を実行しました。テスト用エミュレーターのウィンドウ遷移アニメーションは無効化しています。

- 画面のアクセシビリティノードに、時間・スコア・玉数・ブロック数・速度・効果タイマーが存在することを実際のUI階層で確認。
- ライブ領域への変更イベントを6.5秒間計測し、250msごとの状態変化に対してイベントは最大2回、2回の場合は4.8秒以上の間隔であることを確認。
- intactなマスと再生禁止中のマスはACTION_CLICKなし。空きマスのアクセシビリティアクションで該当する1個だけ再生し、隣接マスは変化しないことを確認。
- 40個の操作領域は全組み合わせで非重複。標準サイズの実際のUI階層では最小86×84px（約49.1×48dp）。一時停止は112×98px（64×56dp）。狭い画面でも各セル自体の最小48dpを検証し、横スワイプで右端を表示後、そのマスだけ再生できることを確認。
- Android 14でタイトル説明はfont_scale=1.0の28px・1行から、2.0では49px・2行へ拡大。開始ボタン文字は31.5px→52.5px、ボタン高は98px→118px。Android 14以降の非線形SP拡大に追従し、全文と各操作はスクロールで到達可能。
- 保存上書き確認の表示・キャンセル・戻るの各段階で保存文字列が一致すること、Activity再生成後に続行できること、明示的な上書き時だけ新しいゲームID・初期盤面が保存されることを確認。
- タイトル・遊び方・設定・ランキング・一時停止・結果・バックグラウンドでは画面点灯フラグが解除され、プレイ・カウントダウン時だけ設定されることを確認。
- 効果・複数指警告の表示でブロックのタップ位置が動かないことを確認。

開発中の試行で見つかった拡大時の確認ボタンの欠け、狭い画面での盤面の縮小を修正しました。また、自動操作の画面端スワイプがOSの戻る操作に入る問題、スクロール停止前のタップ、カウントダウンの一時的な状態への依存を検証手順側で修正。上表は最後まで完走した最終結果のみです。カウントダウンの文字は秒の変化時だけ更新するようにしています。

最終ログは `artifacts/1.0.5/api34-ja-accepted-default.txt`、`api35-en-accepted-default.txt`、`api34-ja-accepted-large.txt`、`api35-en-accepted-large.txt`。UI階層XML・文字サイズJSON・画像も同名フォルダへ保存しています。

署名付き・縮小済みのrelease APKも、この作業で作成したAPI 34の専用エミュレーターへインストールし、versionName 1.0.5 / code 6、起動、カウントダウン、実際の玉の動き、一時停止画面を確認しました。`dumpsys window` でもKEEP_SCREEN_ONがタイトルfalse・カウントダウンtrue・プレイtrue・一時停止falseであることを確認。結果は `artifacts/1.0.5/release-smoke/`。署名の異なる開発版の削除はこの専用エミュレーター内だけで実施し、実機には操作していません。
